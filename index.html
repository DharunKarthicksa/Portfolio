Capacity Insights — Real-Time Fabric Capacity Monitor

A real-time monitoring app for Microsoft Fabric capacities. It streams compute-unit events into Eventhouse, scores every reading against a 4-week hour-of-week baseline to catch anomalies, estimates cost and splits it across teams, checks semantic models against best-practice rules, and docks a Fabric data agent on every screen, so operators can ask why something happened, not just read what.
