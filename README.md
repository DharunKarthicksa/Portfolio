# Dharun Karthick S — Portfolio

A single-page personal portfolio site (Data & AI). Built with plain HTML, CSS, and JavaScript — no build step, no dependencies.

## Structure

- `index.html` — the entire site (styles and scripts inlined).

## Editing

Open `index.html` and search for `TODO` comments to find every spot meant to be personalized:

- Hero tagline
- About / bio
- Skills tags
- Projects (titles, descriptions, tags, links)
- Experience timeline and education
- LinkedIn and GitHub links in the Contact section

## Running locally

Just open `index.html` in a browser, or serve it:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Deploying with GitHub Pages

1. Push this repo to GitHub (see push instructions).
2. In the repo, go to **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to *Deploy from a branch*.
4. Choose branch `main` and folder `/ (root)`, then **Save**.
5. Your site will be live at `https://<your-username>.github.io/<repo-name>/` within a minute or two.

For a personal site at `https://<your-username>.github.io`, name the repository exactly `<your-username>.github.io`.
